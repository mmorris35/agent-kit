# Open questions

What is unresolved, who can answer it, and what is blocked until they do.

Format:

```
## The question, stated plainly
**Needs:** who can answer it.
**Blocks:** what cannot proceed meanwhile. "Nothing" is a fine answer.
**Asked:** when, and where. Blank if it has not been asked yet.
```

Delete a question when it is answered, and put the answer somewhere durable —
a memory file, or `purpose.md` if it changes what the project is.
