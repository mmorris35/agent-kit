# Memory index

One line per memory, loaded at the start of every session. Content lives in the
file it points at — never here.

Format: `- [Title](file.md) — the hook, short enough to scan`

Example:
`- [Deploys need the VPN](deploy-needs-vpn.md) — staging is unreachable otherwise`
