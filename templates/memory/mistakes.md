# Mistakes

What went wrong, and what to do instead. Append; don't tidy. A mistake that is
written down once stops being a mistake that repeats.

Format:

```
## YYYY-MM-DD — one-line description
**What happened:** the observable thing, not the theory.
**Why:** the cause, if it was actually established. "Unknown" is a valid answer.
**Instead:** what to do next time, concretely.
```
